# FAST-LIO 地图录制操作清单

## 一、开机后、移动车辆前

1. 确认 MID360S、工控机和车辆供电稳定，网线与雷达线缆插紧。
2. 打开所有需要导航通过的门，并固定门的位置。
3. 移走临时人员、推车和杂物；不要启动 Nav2、相机检测等高负载程序。
4. 把车放在固定且容易复现的起点，车头方向也要可复现。
5. 打开终端，检查录制空间：

   ```bash
   df -h /home/tang/fastlio_ws/bags/mapping
   ```

   `可用`应不少于 60 GB。本机只有一块系统 SSD，当前建议单次录制不超过 45–60 分钟。

6. 运行完整配置检查：

   ```bash
   cd /home/tang/autoware_map/map_task4/mapping_tools
   ./check_setup.sh
   ```

   绿色项目必须全部通过。DUFOMap、CloudCompare 的黄色提示不影响录包，但会影响后续动态清理和人工修图。

## 二、启动雷达和建图

1. 运行：

   ```bash
   cd /home/tang/autoware_map/map_task4/mapping_tools
   ./00_open_mapping_terminals.sh
   ```

2. 等待两个终端出现：

   - `Mapping 1/2 - Livox MID360S`：雷达驱动；
   - `Mapping 2/2 - FAST-LIO dense mapping`：FAST-LIO 和 RViz。

3. 不要再运行 `/home/tang/fastlio_ws/scripts/00_open_fastlio_terminals.sh`，否则节点和话题会重复。
4. 车辆保持静止至少 10 秒。
5. 在 RViz 中确认点云连续、方向正常，移动车辆少量距离时轨迹连续且地图没有整体抖动。
6. 若任一启动终端报错或 RViz 没有点云，停止操作，不要开始录制。

## 三、开始录制

1. 新开第三个终端。
2. 选择唯一地图名，只使用字母、数字和下划线，例如 `task4_floor1`。
3. 执行：

   ```bash
   cd /home/tang/autoware_map/map_task4/mapping_tools
   ./record_mapping.sh task4_floor1 "一层，门全开，起点=东门"
   ```

4. 等待脚本依次确认以下话题：

   - `/livox/lidar`
   - `/livox/imu`
   - `/cloud_registered`
   - `/Odometry`

5. 看到“录制到……”后仍保持静止 10 秒，再开始移动。

## 四、录制中如何行驶

1. 速度不超过 0.5 m/s，转弯角速度不超过约 30°/s。
2. 路线必须形成闭环：起点 → 所有区域 → 回到同一位置和方向。
3. 长走廊来回各走一遍，尽量让门框、柱子或走廊端部进入雷达视野。
4. 每个房间绕一圈，每个门口来回通过两次。
5. 所有站点、限速区和室内外交接点都要实际到达。
6. 阿克曼车辆不要原地转向，使用大回环或缓慢三点掉头。
7. 跟车人员始终在车辆后方，不能持续进入雷达前方。
8. 观察 RViz；如果地图突然错层、旋转、跳变或点云停止，应放弃本次并重录。

## 五、正确结束录制

1. 回到起点，尽量恢复开始时的位置和车头方向。
2. 保持车辆静止至少 10 秒。
3. 在第三个“录制终端”按一次 `Ctrl+C`，不要关闭窗口或直接断电。
4. 等待脚本完成 MCAP 收尾和频率检查。
5. 确认约有以下频率：

   - 雷达 `/livox/lidar`：约 10 Hz；
   - IMU `/livox/imu`：约 200 Hz；
   - 世界系点云 `/cloud_registered`：约 10 Hz；
   - 里程计 `/Odometry`：约 10 Hz。

6. 如果任何一项低于期望值的 95%，现场重新录制。
7. 记下终端显示的会话路径，例如：

   ```text
   /home/tang/fastlio_ws/bags/mapping/task4_floor1_20261116_143000
   ```

## 六、录完立即检查

假设实际会话目录如下：

```bash
export SESSION=/home/tang/fastlio_ws/bags/mapping/task4_floor1_实际时间
```

1. 查看目录和容量：

   ```bash
   du -sh "$SESSION"
   find "$SESSION" -maxdepth 2 -type f | sort
   ```

2. 查看 bag 信息：

   ```bash
   source /home/tang/fastlio_ws/scripts/fastlio_env.sh
   ros2 bag info "$SESSION/bag"
   ```

3. 确认存在：

   - `$SESSION/bag/metadata.yaml`
   - `$SESSION/meta/session.yaml`
   - `$SESSION/meta/bag_info.txt`
   - 录制使用的 FAST-LIO YAML 和 Livox JSON

4. 原始 bag 未完成备份前不要删除或覆盖。一张地图对应一个会话目录。

## 七、进入自动后处理

```bash
cd /home/tang/autoware_map/map_task4/mapping_tools
./postprocess.sh "$SESSION/bag" "$SESSION/work"
```

完成后阅读：

```bash
less "$SESSION/work/clean/mapclean_report.md"
```

随后按 `本机建图操作流程.md` 完成 CloudCompare 人工复核、区域标注、地图打包和验证。
