# 室外车道图检查与修正

`lanelet2_map_original.osm` 是你发来的原文件，`lanelet2_map.osm` 是修正后的版本。
**没有移动任何点**，只改了车道的左右边界角色、删掉重复车道、补了一段缺失的车道。
使用时把 `lanelet2_map.osm` 拷到 `map_path`（默认 `/home/tang/autoware_map/map_task4/`）下替换原文件。

```bash
python3 check_lanelet.py lanelet2_map.osm          # 检查：反向边界 / 同向重叠 / 断头
python3 fix_lanelet.py lanelet2_map_original.osm lanelet2_map.osm   # 重新生成修正版
```

## 坐标系

车道用的是 local_x / local_y，和 20261117 点云、室内栅格是同一个 `map` 坐标系，不需要变换。
主路（y≈−80 到 −76）、南北向路（x≈60）、北侧环路都和点云里的路面、路缘吻合。

## 修正了什么

| 问题 | 影响 | 修正 |
|---|---|---|
| 14 条车道左边界在行驶方向右侧（30112–30114、930112–930114、50110/50111、950110/950111、970382–970385） | Lanelet2 按"左边界节点 + 右边界节点"判断首尾相接，角色反了路口就接不上：主路和南北向路在 x≈68 的路口完全不连通；可行驶区域、换道判断也会出错 | 交换这些车道的 left/right |
| 整条车道 60110–60112、960110–960112（x 17→182）与分段车道（在 x≈68 路口断开）同向完全重叠 | 同一位置两条同向车道，路线规划会随机选一条，选到整条车道时无法在路口转弯 | 删除这 6 条 |
| 删除后，最南侧车道在 x 17–68 段没有车道 | 这一段只剩两条车道 | 用文件里现成的边界补上东向（980001）、西向（980002，新增一条反向边界 980010） |

修正后：边界反了 0 条，同向重叠 0 条；主路两个方向都能在 x≈68 路口和南北向路连通，东端掉头环连着东西两向。

## 修正后仍存在的路网结构问题（需要你在 Vector Map Builder 里决定）

1. **北侧环路（970376–970390，停车场一圈）和南边路网不连通。** 没有任何车道连过去，车开不进环路。
   其中外圈 970376 → 970377 → 970378 是一条没有闭合的单向线，起点没有前驱、终点没有后继。
2. **路口 x≈68 缺两个转向。** 现在能走的是：主路西行 → 右转北上，南北向路南下 → 左转东行。
   缺"主路东行 → 左转北上"和"南北向路南下 → 右转西行"。所以从南门往北走、或从北边回南门，
   都要先开到东端掉头环再折回来（多绕约 230 m）。
3. **西侧支路（x≈0–4，y −3 到 −30）是死胡同。** 进去的车道在 y≈−29.7 结束，出来的车道没有前驱，
   中间没有掉头连接，开进去就出不来。这段车道里还有几团障碍（约 (0.5, −19.3)、(2.6, −17.2)，像停着的车）。
4. **主路西端（x≈17）是尽头**，西行车道在那里结束。南门交接点在 x=29，在尽头之前，不受影响。
5. **中间车道（B）在东端没有直接接掉头环**，需要先换到两侧车道。中间那两条分隔线是虚线，可以换道，问题不大。

## 和室内的衔接

- 交接点 (29.000, −76.049)：主路最北侧车道中心线上、南门正前方。
  - 进门：Autoware 路线终点设在这里，西行车道（lanelet 950111），车头朝西（yaw −177.37°）。
  - 出门：室内站点 `south_door_out` 在同一点，车头朝东（yaw 2.63°），交权后 Autoware 从东行车道（lanelet 50111）出发。
- 南门在立面 x≈26.9 处。门前有一道 0.15–0.22 m 的路沿坎（x 19–42），车不能从交接点直接往北进门，
  由 Nav2 在主路上掉头、经西头的坡道（x 17.7–24）上到门前平台再进门，全程约 25 m，见 HYBRID_NAVIGATION.md。
