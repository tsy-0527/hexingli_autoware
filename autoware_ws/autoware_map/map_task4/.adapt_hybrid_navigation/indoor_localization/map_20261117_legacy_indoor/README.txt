室内导航用的 2D 栅格（统一 map 坐标系 = 20261117 点云 / 车道图的坐标系）

来源
  旧室内地图 map/indoor_nav_2d、map/indoor_loc_2d、indoor_navigation/maps/speed_mask，
  按 legacy_room_registration.yaml 变换：yaw 3.422°，平移 (11.185, -18.210)，
  2D ICP 墙体点 0.2 m 内 83.9%，中位误差 0.05 m。
  这栋楼是走廊约在 x≈29、y -58 ~ -19 的那栋，南门在立面 y≈-70.8、x≈26.9。

  注意：之前的配准（yaw -0.111°，平移 -11.169, 55.407）是错的，把室内放到了北侧停车场上，已作废。
  当时"20261117 点云没录到这栋楼、走廊被树冠堵死"的结论也是错的：点云里有这栋楼，
  是室内图被放错了位置。

  门前区域（主路、坡道、门前平台）来自 20261117 点云，见 door_apron.yaml。

门前的坎和坡道（2026-11-17 现场点云实测）
  - 路沿坎：x 19–42 整排，比路面高 0.15–0.22 m，东头在 x≈41.8 拐向北接到楼边。
  - 坡道：西头 x 17.7–24，y -75.4 ~ -74.0，两侧栏杆，净宽约 1.2 m，坡道口在西南角（x 17.4–19，宽约 1.5 m）。
    相对路面升高约 0.14 m，坡度约 3%。
  - 坡道西侧平台高出路面约 0.1 m，主路南侧路沿在 y≈-83 ~ -84。
  这些台阶太矮，按离地高度提取不出来，用 --obstacle-line 画成障碍。坡道北侧细栏杆在去动态时
  被误删了约 45% 的点，也一并画上。
  录制时站在主路上的人（x 20.8–21.9，y -77.6 ~ -76.7）已从 door_apron 里清掉。

文件
  nav_map.yaml/.pgm           Nav2 静态层（0.05 m）：室内 + 门前区域，路沿坎/栏杆为障碍，门洞和坡道通道强制可通行
  localization_map.yaml/.pgm  房间全局初始化用（free_thresh 统一改为 0.10，原来 0.25 会把未知当空闲）
  speed_mask.yaml/.pgm        限速掩膜（房间 0.30 m/s；门口、坡道和门前掉头区 0.20 m/s）
  keepout_mask.yaml/.pgm      禁行掩膜：只允许在已建图范围内规划
  door_apron.yaml/.pgm        门前区域（x 6–46，y -86 ~ -68），由 20261117 点云生成
  legacy_room_registration.yaml  配准参数（map_20261117_denoised 里放了同一份）

重新生成（在仓库根目录）
  bash indoor_navigation/tools/rebuild_maps.sh
